有个公司叫 AgentMail，最近拿了 600 万美元种子轮，YC 背景，投资人里有 Paul Graham 和 HubSpot CTO。

他们在做什么？让 AI Agent 有自己的邮箱地址。

现在 AI Agent 能订会议室、能谈合同、能处理客服，但有一个东西一直没有——邮箱。Agent 要和外部联系，要么用人类的邮箱账号，要么就得让人在中间传话。

AgentMail 的方案是给每个 Agent 一个真实的邮箱地址，可以收邮件、发邮件、做 threading、做搜索，全都可以 API 调用，不需要人类介入，不需要 OAuth 设置。

这个东西为什么值钱？因为它解决的是一个关键问题——AI Agent 和真实商业世界的连接点。

你知道现在最卡 AI Agent 扩展的是什么吗？不是说 Agent 能力不够，而是说它能连接的服务太少了。它不能自主注册账号，不能自主收发邮件，不能自主在第三方平台操作——这些事情构成了现实商业里 80% 的流程。

Paul Graham 投这家公司，我觉得他看到的是同一个问题。AI Agent 想要真正改变商业，得先让它能正常“说话”。这个基础问题不解决，其他都是空谈。
