Gumloop 拿了 5000 万美元 B 轮。

这轮是 Benchmark 领投的，对，就是投过 eBay、Uber、Dropbox 的那家。

Gumloop 做的事情很简单——让你不用写代码，拖拖拽拽就能搭出一个 AI 工作流。数据抓取、文档处理、自动报告、多步研究，都能干。

这和 n8n、Zapier 有什么区别？本质上是一样的逻辑，都是工作流自动化。但 Gumloop 专门针对 AI Agent 场景优化过了，它的每一个节点都能跑大模型，能做决策，能接外部工具。

有意思的是他们的客户名单。

Shopify、Ramp、Gusto、Samsara、Instacart。这些公司可不是小客户，都是万人级别的大公司。这意味着 AI 工作流自动化在企业端的真实需求已经被验证了。

Benchmark 投它 的逻辑也好理解——每一家大公司都在想办法让普通员工用上 AI，不需要会编程，不需要懂 Agent 框架，谁都能搭自己的自动化流程。这个体量一旦起来，比程序员用 GitHub Copilot 的体量大多。

就是这种“让不是工程师的人也能用 AI”的工具，现在在 VC 那里是最吸金的赛道之一。
